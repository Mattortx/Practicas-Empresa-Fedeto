## Cómo usar esta documentación

Para la entrega documental, se recomienda entregar o enlazar:

1. README principal del repositorio.
2. Memoria del proyecto para empresa y tutor.
3. Documento de seguridad y privacidad.
4. Esta carpeta de rúbrica.

Para la presentación oral, se recomienda usar:

1. El guion de presentación.
2. El documento de demo y evidencias.
3. El documento de preguntas y defensa.
4. La aplicación funcionando en local o preproducción.

## Mensaje central del proyecto

El proyecto demuestra cómo una empresa industrial puede usar IA de forma prudente para mejorar la entrada de consultas comerciales sin sustituir al equipo técnico. El chatbot es la interfaz visible, pero la lógica principal es un copiloto comercial que clasifica, pregunta, detecta riesgos, resume y deriva.
